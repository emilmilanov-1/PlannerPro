# PlannerPro

PlannerPro е курсов проект на тема **„Интелигентен помощник за планиране на задачи“**. Приложението помага на потребителя да организира задачите си, да определя техния приоритет и да създава подходящ график за изпълнение.

## Основни възможности

- създаване, редактиране, преглед и изтриване на задачи;
- автоматично определяне на приоритет чрез симулирана AI логика;
- класифициране по важност, срок, категория и статус;
- генериране на оптимизиран график;
- съобразяване с почивни дни и официални празници;
- проследяване на напредъка чрез Dashboard и статистика.

## Използвани технологии

- C# и ASP.NET Core MVC;
- Razor Views;
- Entity Framework Core и SQLite;
- асинхронна обработка с `async/await`;
- `HttpClient` за комуникация с външна API услуга;
- автоматични тестове с xUnit.
